# Python File Organizer

My first real world Python project, actually

## About

A Python program that organizes files inside a selected directory considering their file extensions.

## Features

- Scans the directory.
- Identifies extensions.
- Categorizes files.
- Creates category folders.
- Moves files into appropriate folders.

## Fundamentals I used

- pathlib
- shutil
- Dictionaries
- File handling
